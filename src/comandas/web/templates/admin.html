Enviar mensagem pelo WhatsApp

Escreva a mensagem, escolha para quem e clique em Começar envio. O sistema abre a conversa de um cliente por vez com o texto pronto: você aperta enviar no WhatsApp, volta aqui e aperta Enter para ir ao próximo. Só entram clientes que autorizaram receber mensagens (LGPD). Precisa de internet só neste momento do envio.

Muitos clientes? Mande para todos de uma vez pela lista de transmissão do WhatsApp
  1. Clique em Baixar contatos e passe o arquivo para o celular da loja (pelo próprio WhatsApp, e-mail ou cabo). Abra o arquivo no celular e escolha importar contatos.
  2. No WhatsApp (ou WhatsApp Business) do celular: ⋮ → Nova transmissão, marque os clientes (até 256 por lista) e crie a lista. A lista fica salva: nas próximas promoções é só usar de novo.
  3. Escreva a mensagem uma vez só e envie. Ela chega para todos, cada um no privado.
  4. Volte aqui e clique em Marcar todos como enviados, para o histórico ficar certo.

Na transmissão a mensagem é igual para todos (o {nome} não é trocado) e só chega para quem também tem o número da loja salvo — peça para o cliente salvar o contato na hora do cadastro. É o jeito oficial do WhatsApp de mandar para muita gente sem risco de bloqueio.

Segurança

Vale para quem mexe com dinheiro, clientes ou administração (caixa, administrador…): essas contas também saem sempre que o programa é reiniciado, e precisam entrar com a senha de novo. Contas só de cozinha, garçom ou entrada continuam logadas, para a tela da cozinha não parar de mostrar pedidos. Quando a senha de alguém é trocada, essa pessoa sai de todos os aparelhos. Depois de 5 senhas erradas seguidas, o aparelho fica 5 minutos sem poder tentar.
